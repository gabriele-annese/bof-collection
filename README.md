# BOF Collection

This repository contains a collection of different *Beacon Object Files* (BOFs), developed for educational and research purposes.  
I created this project to document, share, and improve my work as I study and experiment with BOF development.

Each BOF is organized in its own folder with source code, a short explanation, and compilation instructions.

> **Disclaimer:** All files and examples in this repository are for *learning*, *research*, and red *team training* in controlled environments only. Do not use them on systems you do not own or have explicit permission to test.
